# Myths of Hasthar

**Myths of Hasthar** is an original multiplayer card game inspired by the dark themes of **greed, gold, sacrifice, and mythology**.

The game features characters and cards such as **Hasthar, Burglar, Goddess, Flour Doll, Gold Coin, and Sacred Line**, creating a strategic game where players must balance greed, risk, and survival.

This project has been developed as a personal passion project by me, **Satyajeet Patil**. The game has been adapted to support **multiplayer gameplay over the same local Wi-Fi network**, allowing multiple players to join and play together using their web browsers.

## 🎮 Features

* Multiplayer gameplay over a **local Wi-Fi network**
* Multiple players can connect and play from their own devices
* Strategic card-based gameplay
* Gold Coins and Flour Dolls as resources
* Hasthar and Burglar mechanics
* Goddess and Sacred Line mechanics
* Game statistics and game-log tracking
* Browser-based interface
* No installation required for players connected to the local network

## 🌐 How to Play

One player runs the game server on a computer connected to the local Wi-Fi network. Other players connect to the host computer using their browser and the provided local network address.

The game is designed to allow everyone to play together from their own devices while sharing the same game state.
